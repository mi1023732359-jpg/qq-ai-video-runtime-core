# ⚠️ DANGER · 危险项说明（必读）

> 本包会在你的电脑上**模拟鼠标点击 QQ 窗口**，并可能在**无人确认的情况下接起视频通话**。
> 这类操作与"播放一段视频"完全不是一个量级：它可能触犯平台条款、泄露隐私、误挂他人电话。
> **默认全部关闭。** 只有读完本文件、并愿意承担后果，才继续配置。

---

## D1. 自动接听（最高危）

| 项 | 说明 |
|---|---|
| 会发生什么 | 有人打来 QQ 视频通话时，程序自动点击"接听"，对方会看到你"已接通" |
| 直接后果 | 对方可能开始说话/展示画面；若 Core 正在录音/转写，会立刻开始采集 |
| 隐私风险 | 可能录到对方未同意被记录的音视频；在中国大陆等地可能涉及《个人信息保护法》告知同意要求 |
| 账号风险 | 非官方客户端行为（UI 自动化）可能违反 QQ 用户协议，存在被限制/封号可能 |
| 可逆性 | 接听后无法"撤销"——对方已经进入通话；只能立刻挂断 |
| 授权凭证 | 管理员确认文件有有效期（默认 24h）并绑定当前窗口指纹；伪造/过期/换指纹都不可用 |
| 兜底 | 三道闸门（窗口指纹 + 管理员确认文件 + 环境变量）缺一不点；探测不确定时判 UNKNOWN 并停手 |

**最低要求**：只用测试账号、只接白名单、先手动验证指纹、全程有人盯着。

## D2. 自动挂断（高危）

| 项 | 说明 |
|---|---|
| 会发生什么 | 到达 `max_call_seconds`、管理员下令、心跳丢失或窗口消失时，程序点击"挂断" |
| 直接后果 | 可能挂断正在正常进行的通话（尤其时长配得太短时） |
| 误判风险 | 窗口识别错误、UI 改版、多显示器坐标偏移都可能点到别处 |
| 重试风险 | 已限制：**含首次在内总点击尝试 ≤ 5 次**（`hangup_max_retries` 默认 2，配置上限 5）+ 退避；耗尽即进入异常，不再点击 |
| 可逆性 | 通话被挂断不可恢复 |

**建议**：先只开自动挂断、`max_call_seconds` 设大一点（如 600），跑几轮再收紧。

## D3. UI 自动化（模拟鼠标/键盘操作）

| 项 | 说明 |
|---|---|
| 会做什么 | 枚举顶层窗口（只读）、必要时 `SetCursorPos` + `mouse_event` 做**单次**点击 |
| 不会做什么 | 不注入 DLL、不改 QQ 文件、不伪造协议包、不绕过平台安全机制 |
| 误点风险 | 点击前校验 hwnd/类名/窗口尺寸/点位；任何不一致 → 不点 |
| 焦点风险 | 点击前会 `SetForegroundWindow`，可能抢走你正在用的窗口焦点 |
| 多显示器/DPI | 已做 per-monitor DPI 感知，但 125%/150% 缩放下仍需实测确认 |
| 平台变更 | QQ 改版后指纹失效 → 扩展判 UNKNOWN 并停手（不会盲点），但需要重新采集 |

## D4. 与 Core 的联动风险

- 通话期间 Core 会持有"发送租约"，普通主动消息暂停（这是设计，不是 bug）。
- 接听成功但 Core 状态没跟上 → 扩展判异常并请求挂断，**不会假装成功**。
- 崩溃/重启后不会自动恢复未经确认的自动接听（启动时显式 `set_auto_answer(false)`）。

## D5. 数据与日志

- 审计日志（JSONL）会记录 caller、call_id、动作结果；**不含密码/API Key/token**（键名脱敏）。
- 日志默认不提交（`.gitignore`），但**你自己机器上会留档**，分享前自行脱敏。
- 本包不联网、不上传任何数据。

## D6. 合规与使用边界（明确禁止）

以下用法**明确禁止**，作者不提供任何支持：

1. 用于监控、跟踪、骚扰他人。
2. 在未告知对方的情况下录制/转写通话。
3. 接听非本人可接听的账号来电（如代接他人 QQ）。
4. 绕过平台风控、批量多开、倒卖"自动接听"能力。
5. 在生产主号上直接开启自动接听。
