# SECURITY · 高风险通话控制扩展

> 本模块会**模拟用户操作去点 QQ 的窗口**，属于本仓库中风险最高的可选能力。
> 默认关闭；不满足授权条件时一律拒绝动作（fail-closed）。

## 1. 高风险权限清单

| 能力 | 风险 | 默认 | 需要的显式授权 |
|---|---|---|---|
| 窗口枚举（只读） | 低：可看到他窗口标题 | 关（扩展关闭时不运行） | `enabled=true` |
| 模拟点击（鼠标） | **高**：会操作其他应用窗口 | 关 | `enabled` + `enable_auto_answer` + 指纹 + 确认文件 + 环境变量 |
| 自动接听 | **高**：未经本人同意接起通话/采集音频 | 关 | 三道闸门缺一不可；任一被配置关闭即整体失效 |
| 自动挂断 | **高**：可能挂断正在进行的通话 | 关 | `enabled` + `enable_auto_hangup` |
| 与 Core 会话交互 | 中：影响租约/会话状态 | 关 | 由调用方显式注入协调器 |

## 2. 自动接听风险

- 陌生人来电可能被接起 → 对方会进入"通话中"，可能触发录音/转写（取决于 Core 配置）。
- 若 `allow_uins` 配错，可能接起不该接的人 → 建议只用白名单，且先小范围验证。
- 接听后如果 Core 状态没跟上（UI 成功但协调器失败），扩展会进入异常并请求挂断，**不会假装成功**。

## 3. 自动挂断风险

- 误挂：`max_call_seconds` 太小会把正常通话挂掉。
- 重试失控：已用"最大重试次数 + 退避 + 全局动作限流"约束；重试耗尽即进入异常，不再点击。
- 挂断失败：不会伪造"已挂断"；会通知管理员并保持异常状态，等待人工处理。

## 4. 误操作可能性与缓解

| 可能 | 缓解 |
|---|---|
| QQ UI 改版导致按钮位置变化 | 点击前校验窗口类名/尺寸；指纹不匹配 → 判 UNKNOWN，不点击 |
| 多个窗口被误判为通话窗口 | 多个候选 → UNKNOWN，不动作 |
| 自己的操作触发二次来电 | 同一 call_id / automation_id 幂等，重复事件不重复点击 |
| 扩展被误启用 | 三层独立开关；重启时按当前配置单向同步协调器开关，不沿用 Core 旧值 |
| 确认文件重放/长期复用 | 必须含 `issued_at`（默认 24h 过期）与指纹 SHA256 绑定，不符即拒绝 |
| 绕过闸门 | 任一闸门被配置关闭 → 自动接听整体失效 |
| 句柄复用误点 | 点击前再校验 pid / 进程名 / 类名 / 尺寸，任一变化即拒绝 |
| 审计日志泄露账号 | 日志脱敏（password/token/secret/cookie 等键名一律替换） |

## 5. 管理员控制（最高优先级）

- `runtime.stop()` / 停止文件：立即停手，任何自动动作都不再执行。
- `runtime.force_hangup()`：强制挂断当前通话（Core 侧 `force_hangup`）。
- `runtime.deny_current()`：拒绝当前来电（不点击）。
- `runtime.clear_abnormal()`：人工确认后清除异常状态。
- 管理员 UIN（`admin_uins`）不受免打扰限制，但仍受黑名单以外的基本检查。

## 6. 故障处理

| 故障 | 行为 |
|---|---|
| 配置缺失/非法 | 视为关闭（`enabled=false`），不动作 |
| 指纹/确认文件缺失 | 不点击，记录 `fingerprint_missing` / `confirm_missing` |
| 环境变量未开 | 不点击，记录 `env_flag_missing` |
| 探测失败 / 多候选 | 判 UNKNOWN，不动作 |
| 点击失败 | 记录 `click_failed:*`，不重试点击（接听） |
| 接听后状态不对 | 进入 abnormal，请求 Core 挂断，不宣告成功 |
| 挂断失败 | 有限重试后进入 abnormal + 通知管理员，不伪造成功 |
| 审计写失败 | 计数 `write_failures`，不阻断主流程 |

## 6.1 残余风险（无法完全消除）

- **同机同用户的确认文件伪造**：本包没有密钥体系，能改文件的人也能伪造确认；确认文件只防「误操作」，不防「本机恶意用户」。
- **QQ UI 改版**：类名/布局变化会让点击失效或点到别处；扩展会先判 UNKNOWN 停手，但需要人工重采指纹。
- **DPI/多屏**：已做 per-monitor DPI 感知，仍需实机验证。

## 7. 边界（明确不做）

- 不注入 DLL、不修改 QQ 客户端文件、不模拟协议封包、不绕过平台安全机制。
- 不读取/记录账号密码、API Key、cookie、token。
- 不默认开放远程控制接口；不接受"普通聊天消息"里的管理员指令。
- 不把模拟测试结果描述成真实 QQ 验证结果。
